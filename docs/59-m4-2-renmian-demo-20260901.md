## 3. demo SQL 结构（基于 639-A.2）

**`scripts/seed_m4_2_demo.sql` 结构：**

| 表 | 行数 | demo 隔离列 | 备注 |
|---|---|---|---|
| source_registry | 1 | — (单条 synthetic) | `domain='demo.placeholder'` `enabled=FALSE` |
| source_document | 1 | `file_hash_sha256='0…01'`（确定性 demo SHA） | source_level=S4, verification_status=UNVERIFIED |
| position | 5 | — (015 未加 position.is_demo 列) | 由下游按 `source_document.file_hash_sha256` 关联过滤 |
| person | 5 | `is_demo=TRUE` | `last_verified_at=NOW()` |
| tenure | 5 | — (015 未加 tenure.is_demo 列) | `source_id = demo source_document` |
| appointment_event | 5 | `is_demo=TRUE` | `tenure_id` FK → 上 5 条 demo tenure; `source_id = demo source_document` |

**is_demo 隔离原则**：
- 全部 5 person + 5 appointment_event 显式 `is_demo=true`（015 加列约束）。
- 全部 5 tenure 通过 `source_id → demo source_document(SHA 0…01)` 间接隔离。
- 全部 5 position 通过 `source_document.file_hash_sha256` 关联过滤（无 is_demo 列）。
- demo 数据**只能** SELECT 通过 `WHERE is_demo=true` 过滤（应用层 + 测试层）。
- 真实数据 INSERT 必须 `is_demo=false` + `source_id NOT NULL`（016+ 引入 CHECK 约束）。

**read-only 红线遵守**：
- ✓ 不删表 / 不 DROP COLUMN / 不 DELETE FROM 真实数据（仅 INSERT ON CONFLICT DO NOTHING）。
- ✓ 不修改 source_registry 既有行（demo 单条独立 synthetic）。
- ✓ 不动 mart_*.sql / 4 frontend fixture bytes。
- ✓ 不写 cegr.observation 真实行。
- ✓ 不静默硬编码 GDP 值（demo 表无 GDP 字段）。
- ✓ demo 数据 ≤ 5 条 person/tenure/appointment_event（避免镀铬）。
- ✓ 不宣称 Gate / O1 / M2 / M4 PASS。

**demo 数据选择理由**：
- 5 person 行（demo-person-1..5）覆盖：3 个 current tenure + 1 个 ended tenure + 1 个 removal appointment_event（演示 appointment_event.event_type 多样性）。
- 5 tenure 行全部 `source_id = demo source_document(SHA 0…01)`，一跳回 SHA 用于 demo 一跳回验证。
- 5 appointment_event：4 个 appointment + 1 个 removal（演示 event_type 字段；不涉及真实任免）。
