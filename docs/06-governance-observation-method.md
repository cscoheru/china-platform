# 06 — 治理效能观察方法（Governance Observation Method）

> Stage 0 交付物 #06；对应 PRD 第 15 章第 7 项 + 第 6 章。
> 设计目标：**让"是否尽职"从主观判断变成有证据链、带不确定性的可复核观察**。

## 1. 名称和边界（per PRD 6.1）

- **首期统一使用**：治理效能观察 / 政府运行效能观察
- **不使用**：官员尽职评分 / 官员能力总分 / 官员贡献度
- **原因**：公开数据不能直接观察主观努力、内部决策质量、不可公开约束
- **本质**：是观察框架，**不是评分系统**

## 2. 六段证据链（per PRD 6.2）

每一条治理效能观察都应当能够拆解为以下六段，缺一不可：

```
┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│  1.CONDITION│───▶│2.COMMITMENT │───▶│  3.INPUT    │
│   条件      │    │   承诺      │    │   投入      │
└─────────────┘    └─────────────┘    └─────────────┘
                                            │
                                            ▼
┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│5.OUTCOME_   │◀───│  4.PROCESS  │◀───│             │
│   RISK      │    │   执行      │    │             │
└─────────────┘    └─────────────┘    └─────────────┘
```

### 2.1 条件（CONDITION）
观察对象继承的发展基础：
- **区位**：交通枢纽/沿海沿边/资源产地
- **资源**：土地/水/能源/矿产/生态
- **产业基础**：主导产业、产业链位置、上市公司
- **人口**：规模、结构、流入流出、人力资本
- **人才**：高校、研发、就业市场
- **历史债务**：财政/企业/银行三角债
- **全国周期**：与观察期叠加的宏观环境

### 2.2 承诺（COMMITMENT）
地方主政者公开提出的目标：
- **政府工作报告**：年度目标、五年规划目标
- **预算报告**：收入与支出目标
- **政策文件**：专项行动、试点承诺
- **任前公示**：任职发言中的目标
- **重大活动**：招商签约、开工动员中的承诺

**关键约束**：
- 承诺必须**可验证**——抽象口号不入证据链
- 承诺必须**有时点**——"努力做好"不算承诺，"三年内引进 100 家规上工业企业"算
- 承诺的来源**写入承诺记录**：`policy_document` + `government_commitment` 表

### 2.3 投入（INPUT）
为兑现承诺投入的资源：
- **财政**：一般公共预算 + 政府性基金 + 国有资本经营 + 债务限额
- **土地**：用地指标、收储出让、划拨
- **融资**：平台公司、城投债、银行授信、产业基金
- **组织**：机构编制、领导小组、专班
- **政策工具**：税收优惠、补贴、规制豁免

### 2.4 执行（PROCESS）
资源转化为产出的过程：
- **预算执行**：执行率、绩效自评、调整次数
- **审批时长**：项目立项到开工天数
- **项目节点**：签约 → 开工 → 投产 → 达产
- **政策落地**：配套实施细则、配套资金
- **信息公开**：公开率、回应率、12345 投诉处理
- **问题纠偏**：审计整改、巡视整改、人大监督

### 2.5 产出（OUTPUT）
直接结果（不评价好坏，只列数量）：
- 设施建成（公里/座/兆瓦）
- 服务供给（学位/床位/户）
- 企业和项目落地（注册数/签约数/开工数/投产数）
- 就业岗位（新增/失业率）
- 吸引投资（金额，不评价"含金量"）

**注意**：签约≠开工≠投产≠达产，四种状态分别记录（per PRD 5.4）

### 2.6 结果与风险（OUTCOME_RISK）
中长期效果：
- **收入**：人均/总量/结构
- **生产率**：劳动生产率/全要素生产率
- **就业**：失业率/就业结构/工资增长
- **创新**：专利/R&D/技术合同
- **公共服务**：教育/医疗/养老/住房满意度
- **生态**：污染排放/碳强度/灾害损失
- **债务**：负债率/利息保障倍数/隐性债务
- **房地产**：量价/去化/空置率
- **人口**：出生率/净流入/老龄化

### 2.7 证据链缺失的处理

如果某段缺失：
- 在 `inference_record.evidence_gaps` 中记录
- 在产品层展示时**显著标记"X 段未覆盖"**
- 不得用相邻段的证据"补位"

## 3. 七维度观察（per PRD 6.3）

证据链映射到以下 7 个观察维度。每个维度**不直接评分**，而是给出**维度卡 + 证据摘要 + 同类区间**：

| 维度 | 主要证据来源 | 风险 |
|---|---|---|
| 政策兑现与政务透明 | 政府工作报告、五年规划、预算报告、信息公开年报、回应率、统计修订说明 | 抽象承诺、目标漂移、公开 ≠ 易读 |
| 财政执行 | 决算、预算执行通报、绩效自评、审计报告 | 调整预算、决算时滞 |
| 项目交付 | 审批平台、招投标、公共资源交易 | 签约注水、烂尾 |
| 经济适应 | 统计公报、税收、产业用电、专利 | 短期波动 vs 长期趋势 |
| 公共服务 | 教育/医疗/养老统计公报、12345 | 满意度抽样代表性 |
| 风险管理 | 债务限额、土地出让金、房地产销售、生态公报 | 隐性债务、报表美化 |
| 目标一致性 | 工作报告 vs 实际数据、第三方评估 | 因果 vs 相关 |

**注意**：PRD 6.3 列了 8 个维度（包含"目标一致性"和"政策兑现"作为分项）。本框架保留 7 维度：把 PRD 中"目标一致性"与"政策兑现"合并为表首行的"政策兑现与政务透明"，另设"目标一致性"做反向佐证。表中**实际可见的 7 行**即最终基线，PRD 8 项映射关系见下表。

| PRD 6.3 维度 | 本框架 7 维度 |
|---|---|
| 目标一致性 | 目标一致性（独立行） |
| 政策兑现 | 政策兑现与政务透明（合并行） |
| 政务透明 | 政策兑现与政务透明（合并行） |
| 财政执行 | 财政执行 |
| 项目交付 | 项目交付 |
| 经济适应 | 经济适应 |
| 公共服务 | 公共服务 |
| 风险管理 | 风险管理 |

## 4. 分析方法等级（per PRD 6.4，证据从弱到强）

| 等级 | 方法 | 适用条件 | 产物 |
|---|---|---|---|
| L1 | 自身趋势：本地区过去对比 | 始终可用 | 时间序列图 |
| L2 | 同类比较：与基础/人口/产业/区位相近地区对比 | 有可比地区 | 同类排名 + 同类区间 |
| L3 | 条件化表现：控制初始条件 + 全国年份效应 + 行业结构 + 上级政策 | 数据充足 | 残差序列 |
| L4 | 面板固定效应：区分长期地区特征与共同年度冲击 | 长面板 | FE 系数 |
| L5 | 事件研究：观察政策/任期变化前后路径 | 政策可识别 | 前后对比图 |
| L6 | 双重差分：处理组/对照组/平行趋势可信 | 强假设 | DiD 估计 |
| L7 | 合成控制：重大政策/冲击的反事实 | 单一处理单元 | 合成对照路径 |

**纪律**：
- L1-L3 始终可做；L4+ 需要数据条件充分
- L5-L7 必须记录 model_specification + comparison_group 入库
- 任何等级的输出**不得命名为"贡献"**，建议用"条件化相对表现"/"未解释差异"/"与任期重合的变化"

## 5. 任期归因约束（per PRD 6.5）

### 5.1 多职位记录
- 党委、政府、人大、政协、关键部门分别建 `position` 表
- 同一地区同一时期可能多人共同决策 → 重叠任期需记录
- 不把不同职位混为一谈

### 5.2 跨任期项目
- 重大项目和产业政策通常跨任期
- 必须记录：提出者 → 批准者 → 开工者 → 投产者 → 见效者 → 责任时段切分

### 5.3 结果滞后
- 经济、生态、人口等结果指标**必须设置 1-3 年或更长滞后**
- 进行敏感性分析：1y / 3y / 5y 三档对照

### 5.4 不可作为绩效验证的信号
- **晋升**：可能与上级偏好、跨地区调动、年龄梯队相关，不直接证明绩效
- **调任**：可能与任期届满、回避制度、纪律处分相关，不直接证伪
- **媒体评价**：S3/S4 级，不作单独定论依据

### 5.5 负面事件的归因
- 必须区分**长期积累 / 外部冲击 / 当期处置**
- 例：某地暴雷 → 是历史债务（条件）+ 全国地产周期（外部）+ 处置节奏（当期）的组合
- 不可仅归因于"现任未尽职"

## 6. 综合指数的纪律（per PRD 6.6）

**首期不建立单一总分**。

如果后期建立，**必须同时公开**：

1. 指标和权重
2. 缺失值处理
3. 标准化方法
4. 异常值处理
5. 置信区间
6. 权重敏感性
7. 数据覆盖率
8. 是否受行政区划和统计口径变化影响

任何指数都必须能**一键回放**：换一组权重/换一种缺失值处理 → 结论是否依然成立？

## 7. 产物的展示形式

每个地区观察页面包含：
1. **条件卡**：CONDITION 段摘要（基线年 + 最新年）
2. **承诺清单**：当前在期承诺 + 历史承诺兑现跟踪
3. **投入仪表**：财政、债务、土地、组织的当期数据
4. **执行时间轴**：项目/政策的进度节点
5. **产出摘要**：本期已投产/已开工/已签约清单（**标明状态**）
6. **结果 vs 风险**：5 个核心结果指标 + 3 个风险指标
7. **同类对比**：3-5 个可比地区 + 同类区间
8. **证据链接**：每条数据可点击回到原始 source_document

**不展示**：
- 总分
- 排名（除非与同类区间一起展示）
- "该官员表现好/差"的简单陈述
