## 2. 范围与边界（Scope Confirmation）

### 2.1 时间范围（per PRD 2.1）
- 核心年度序列：**2001 年起**（中国加入 WTO 起点）
- 历史基线：**1995–2000**（用于识别入世前后变化，关键指标）
- 当期监测：国家/省级月度+季度+年度；地级市按公开频率；区县年度
- 每个数据点保存"统计期"和"发布日期"两栏，不得混淆

### 2.2 地理范围（per PRD 2.2）
- 国家：中国大陆总体
- 省级：31 个大陆省/自治区/直辖市（不含港澳台，单独建口径）
- 地级：地级市、地区、自治州、盟
- 县级：市辖区、县、自治县、旗、县级市，按优先级逐步纳入

### 2.3 行政区划版本（per PRD 2.3）
- 时变行政区划模型：`geo_entity` + `geo_code_version` + `boundary_change_event`
- 必须记录：规范 ID / 区划代码 / 统计用代码 / 层级类型 / 上级 / 有效起止 / 撤县设区/撤地设市/合并/拆分/更名 / 前身继承
- 跨期比较必须声明边界是否可比

### 2.4 主题范围（12 类 per PRD 2.4）
1. 总量与增长  2. 需求结构  3. 产业结构  4. 企业活力  5. 人口与人才
6. 财政与债务  7. 金融  8. 资源与环境  9. 基础设施与公共服务
10. 创新与数字化  11. 开放程度  12. 政府行为
