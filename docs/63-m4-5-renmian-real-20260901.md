### 2.2 排除原因详解

- **黑龙江（SHA 撞 641）**：`26e5379d…b87ab` 已在 641 INSERT 中使用；642 重抓同 URL → 同 SHA → 违反 "真实 SHA ≠ 641 real SHA" 红线；故排除。
- **福建（任免 anchor 未匹配）**：landing 200 OK 但页面 anchor 中无 `任免|任命|免职|任免职` 关键词；需更宽松正则或 sub-path 探测。
- **云南（http_count 撞上限）**：landing 200 OK 后已无 detail fetch 余量（HTTP_LIMIT=12，实测 10/12 时 yunnan 阶段已无 detail 配额）。
